Sobre mí

Soy David Pérez Velasco, ingeniero informático por la Universidad de Salamanca y ahora cursando el máster en Ingeniería Informática. Empecé con Java y acabé aterrizando en el desarrollo web: TypeScript, React y Node.js, con Spring Framework en la parte de backend. Mi TFG, DocumentChain, junta blockchain (Ethereum), IPFS y cifrado para gestionar documentos con trazabilidad y control de acceso. Me gustan los proyectos donde hay sistema y producto a la vez: base de datos de verdad, autenticación y una interfaz que no estorbe. Aquí cada proyecto explica qué es, cómo está hecho y cómo se ejecuta y se prueba.
