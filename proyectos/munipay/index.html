MuniPay

Consultar las cuentas del equipo sin depender de una hoja de cálculo.

Dato:Versión web publicada y aplicación Android disponible para descargar.

Abrir aplicación ↗Código en GitHub ↗
  • Flutter
  • Dart
  • Firebase Auth
  • Firestore
  • Provider

MuniPay salió de las cuentas de mi equipo de fútbol: multas, pagos y gastos que llevábamos en una hoja de cálculo. La aplicación reúne esos movimientos y permite que cada jugador consulte su situación.

Llevar las cuentas del equipo

El administrador registra multas, pagos y gastos compartidos. Los jugadores acceden al equipo con un código de invitación y pueden consultar lo que tienen pendiente.

Los resúmenes se actualizan cuando cambian los datos. También se pueden exportar a Excel para revisar las cuentas fuera de la aplicación.

Web y Android

La versión web está disponible aquí y se utiliza desde el navegador.

La versión Android se descarga desde GitHub. Ambas versiones comparten la misma base de código en Flutter.

Cómo está organizada

La aplicación distingue las acciones del administrador y las del jugador. Firebase gestiona las cuentas y los datos del equipo; la interfaz muestra los movimientos y sus resúmenes.

Desarrollo

La aplicación está publicada y sigo revisando los recorridos de gestión y la presentación de las cuentas.

Dato

Versión web publicada y aplicación Android disponible para descargar.

Las cuentas de un equipo

Las multas, los pagos y los gastos compartidos pueden acabar repartidos entre mensajes y hojas de cálculo. MuniPay los reúne para que el administrador pueda llevar la cuenta y cada jugador consultar lo que le corresponde.

Los registros

  • Equipo y miembros: quién forma parte del grupo y qué papel tiene.
  • Multas: importes registrados por el administrador para cada jugador.
  • Pagos: movimientos que permiten llevar el seguimiento de lo abonado.
  • Gastos compartidos: costes del equipo que se reparten entre miembros.

Consultar y exportar

Los resúmenes permiten revisar la situación de cada jugador y del equipo. La exportación a Excel mantiene una forma de consultar esos datos fuera de la aplicación.

Una aplicación para web y Android

Flutter y Dart permiten mantener ambas versiones en una misma base de código. La distribución pública es una aplicación web y un APK para Android.

Cuentas y datos

Firebase Authentication gestiona el acceso y Firestore almacena los equipos, miembros y movimientos. La interfaz recibe las actualizaciones de datos y presenta los resúmenes.

Las reglas de acceso distinguen las acciones de administración de las consultas de los jugadores.

Exportación

La aplicación genera archivos Excel para revisar las cuentas sin depender de la interfaz. El detalle de la implementación está en GitHub.

Consultar las cuentas

El administrador puede crear el equipo, incorporar jugadores y registrar multas, pagos y gastos. Los jugadores se unen mediante un código de invitación y consultan su situación.

El resumen muestra los movimientos y las cantidades pendientes. La exportación a Excel permite revisar o compartir las cuentas fuera de la aplicación.
