CDMPLab is a **tactical board and exercise library** for football coaches. It lets a coach place
players and equipment, draw movements, add text and save every composition in a folder-based library.

The challenge was not drawing a pitch. It was making selection, dragging, rotation, resizing, zoom
and orientation changes feel predictable with both a mouse and a small touch screen.

## What works today

- Full pitch, half pitch, transverse 7-a-side pitch and blank canvas.
- Players, balls, cones, poles, mini goals, shapes, arrows and text.
- Formation templates, duplication, folders, sessions and export.
- Local mode and team management with different permissions.
- Authentication and team-level data isolation through Supabase Row Level Security.
- Unit tests and Playwright E2E journeys, including the production build.

## A decision you cannot see

Screens never talk directly to Supabase. They use an interchangeable data source: local storage while
developing or a remote repository after sign-in. That makes interaction testing independent from the
network and keeps security as a database responsibility.

## Next steps

The web version is published on GitHub Pages. I am preparing it for more coaches: reviewing editor errors, improving the first visit and checking permissions and account recovery.

A published interface does not mean every registration, invitation and collaboration flow has been verified for general access. That review is part of the remaining work.
