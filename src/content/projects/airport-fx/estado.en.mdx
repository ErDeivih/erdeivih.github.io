## What runs today

```powershell
git clone https://github.com/ErDeivih/airport-fx-data-platform.git
cd airport-fx-data-platform
uv sync --group dev --group design
uv run ruff format --check .
uv run ruff check .
uv run pytest -q
uv run python -X utf8 scripts/validar_documentacion.py
```

The numerical design check uses a separate dependency group:

```powershell
uv run --group design python -X utf8 scripts/validar_diseno.py
```

## What I do not claim yet

The repository is in its first phase. It does not yet download sources over HTTP or write the bronze
layer; it also does not contain the dbt project, Power BI report or forecasting results. The README
keeps those items in the roadmap and leaves improvement percentages blank until reproducible
backtesting exists.

That distinction is deliberate: in a data project, documenting uncertainty and unfinished work is
as important as the completed pipeline.
