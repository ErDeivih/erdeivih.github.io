FX Aeropuertos is a data project in preparation. It starts with an exchange office's question: how much cash in each currency is needed to meet demand without keeping unnecessary stock?

## What I want to study

Selling currency reduces stock; buying it replenishes stock and consumes euros. The planned analysis separates these flows to study each office's requirements.

## Sources

The design considers public exchange rates, tourism, passenger figures and calendars. These sources do not include individual exchange transactions, so the project separates observed information, estimates and simulated transactions.

## Remaining work

Source collection, the data model and reports still need to be completed. Forecasts and inventory decisions can then be evaluated using measured results.

## Availability

[The repository](https://github.com/ErDeivih/airport-fx-data-platform) contains the project's starting point and design. There is no published application, public dashboard or forecasting result yet.
