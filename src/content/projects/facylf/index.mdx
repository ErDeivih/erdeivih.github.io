FACyLF será una web para seguir el **fútbol federado de Castilla y León** sin tener que saltar entre
páginas o buscar cada competición por separado.

La idea es reunir resultados, clasificaciones y estadísticas en una interfaz clara, pensada tanto
para consultar la última jornada como para seguir la evolución de un equipo durante la temporada.

## Qué quiero resolver

- Encontrar rápido una competición, categoría o equipo.
- Consultar jornadas, resultados y clasificación desde el móvil.
- Presentar las estadísticas sin convertir cada pantalla en una tabla interminable.
- Mantener una navegación coherente entre temporadas y competiciones.

## Antes de empezar a construir

El primer trabajo será concretar qué datos están disponibles, con qué frecuencia se actualizan y qué
condiciones de uso tienen. A partir de ahí podré definir el modelo de competiciones, equipos, partidos
y estadísticas, y elegir una arquitectura que no complique el proyecto antes de tiempo.

## Estado real

Es un proyecto futuro. El repositorio está reservado, pero la aplicación todavía no está montada.
Esta ficha recoge la intención y se irá completando cuando existan decisiones y avances que enseñar.
