## An academic prototype

DocumentChain is a research and development project, not a public storage service. Code and documentation are available on [GitHub](https://github.com/ErDeivih/DocumentChain).

## What can be explored

The project environment supports uploading a document, viewing its version and managing access permissions. It includes the web application and its storage and record components.

## Reproduce the project

The repository explains how to prepare the environment with Docker and a development network. Installation instructions and sample data are kept there alongside the code version.

There is no deployed public demo yet.
