## Requirements

- Docker Desktop
- Git

## Boot it up

```bash
git clone https://github.com/ErDeivih/DocumentChain.git
cd DocumentChain
docker compose up -d --build
```

The first time takes **~5 minutes** (image downloads and compilation). Subsequent starts are
`docker compose up -d` (about 30 seconds).

## Test users

The backend generates two users automatically on start:

| User | Password | Role |
|------|----------|------|
| `admin` | `Admin1234` | ADMIN |
| `david` | `David1234` | USER |

## Test the smart contracts

```bash
cd smart-contracts
npm install
npx hardhat test
```

This checks that the Ethereum contracts behave as expected. To test the whole app, open the
frontend (`http://localhost:5173`), log in with the users above and try uploading a document, seeing
its version and sharing access.
