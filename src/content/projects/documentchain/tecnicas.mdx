## Interfaz y coordinación

React y TypeScript forman la interfaz web. Una API en Node.js y Express coordina las operaciones con el almacenamiento y los contratos.

## Documentos y versiones

Los contratos están escritos en Solidity. El contenido se almacena en IPFS Cluster con varios nodos y Nginx como balanceador.

El cifrado del archivo utiliza AES-256-GCM y el intercambio de claves utiliza ECIES. El documento cifrado y el registro de su versión se gestionan por separado.

## Entorno del proyecto

Docker Compose reúne las piezas del prototipo, incluida la red de desarrollo. La documentación del [repositorio](https://github.com/ErDeivih/DocumentChain) describe la arquitectura y cómo reproducirla.
