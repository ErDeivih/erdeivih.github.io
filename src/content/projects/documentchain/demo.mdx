## Un prototipo académico

DocumentChain es un trabajo de investigación y desarrollo, no un servicio público de almacenamiento. El código y la documentación están disponibles en [GitHub](https://github.com/ErDeivih/DocumentChain).

## Qué se puede explorar

El entorno del proyecto permite recorrer la subida de un documento, consultar su versión y gestionar permisos de acceso. Incluye la aplicación web y las piezas de almacenamiento y registro que la acompañan.

## Reproducir el trabajo

El repositorio explica cómo preparar el entorno con Docker y una red de desarrollo. Las instrucciones de instalación y los datos de ejemplo se mantienen allí para acompañar a la versión del código.

Por ahora no hay una demo pública desplegada.
