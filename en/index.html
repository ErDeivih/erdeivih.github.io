About me

I'm David Pérez Velasco, software engineer from the University of Salamanca, now doing an MSc in Computer Engineering. I started with Java and ended up in web development: TypeScript, React and Node.js, with Spring Framework on the backend. My final project, DocumentChain, combines blockchain (Ethereum), IPFS and encryption to manage documents with traceability and access control. I like projects that mix system and product: a real database, authentication and an interface that doesn't get in the way. Here each project explains what it is, how it's built and how to run and test it.
